What it lets you do

  • Run it anywhere. Personal, academic or commercial use, on as many machines as you like, at no cost.
  • Change it. Fork the source, strip the calendar card out, rewrite the timer — no permission needed.
  • Pass it on. Bundle Nectar into another product, or sell a build, as long as the copyright notice and the permission notice travel with it.

What it does not give you is a warranty: if the timer misses a meeting, the licence says the authors are not liable. Keep the notices, and you are done — MIT has no copyleft clause, so your own changes can stay closed if you want them to.

Redistributing a build? Ship the licence text beside the binary, and a self-signed or missing code signature will still make Windows warn about the publisher — that is separate from the licence.

Third-party components

Nectar is native C# rather than a bundled browser, so the list is short. These are the pieces that end up in a published build, with their own terms:

ComponentLicenceNotes
Windows App SDK · WinUI 3 MIT Microsoft. Copied beside the executable, because Nectar ships self-contained.
.NET 8 runtime MIT Microsoft. Bundled in the publish folder, so nothing needs installing first.
Entity Framework Core + SQLite provider MIT Microsoft. Reads and writes nectar.db.
Microsoft.Win32.SystemEvents MIT Microsoft. Notices when the PC suspends or the display changes.
SQLite Public domain The SQLite authors dedicated it to the public domain.
Bricolage Grotesque · Instrument Sans · IBM Plex Mono SIL Open Font License 1.1 Headings, body and code on this site, served through Google Fonts.

The Windows SDK build tools are used to compile and sign but are not redistributed, and there are no other third-party libraries in the app — no Electron, no web view, no charting package.

The name and the bird

The MIT licence covers the code. It does not hand over the Nectar name or the hummingbird mark, which identify this project: a fork is welcome, but it should ship under its own name and icon so people can tell the two apart. The logo itself is included in the repository for building and distributing Nectar, not for unrelated branding.

Contributions

Bug reports, fixes and features are welcome in the repository. Anything merged is accepted under the same MIT terms, so the project stays equally free for everyone who picks it up next.
